# Weed Detector — MVP детекции сорняков на снимках с дрона

Хакатонный MVP: детекция сорняков (YOLOv8) на аэрофотоснимках с полей,
с тайловым (tiled) инференсом для больших UAV-изображений и веб-демо на Streamlit.

## Данные

Исходный датасет `Сорняки/<Вид сорняка>/<Фаза роста>/*.jpg` — это
классификационный набор (кропы отдельных растений), **без bounding box
разметки**. Чтобы получить рабочий детектор, `src/prepare_dataset.py`
автоматически генерирует псевдо-bbox для каждого фото: растение
сегментируется по индексу избыточной зелени (ExG) с порогом Отсу,
берётся bounding rect найденного объекта (с fallback на центральную
область кадра, если сегментация не удалась). Классы детектора = виды
сорняков.

## Установка

```bash
pip install -r requirements.txt
```

## Подготовка датасета (YOLO-формат)

```bash
python src/prepare_dataset.py
```

Создаёт `data/images/{train,val}`, `data/labels/{train,val}` и `data/data.yaml`.

## Обучение baseline-модели

```bash
python src/train.py
```

Опции: `--epochs`, `--imgsz`, `--batch`, `--device` (по умолчанию `cpu`).
Лучшие веса сохраняются в `models/best.pt`.

## Проверка инференса из консоли

```bash
python src/inference.py path/to/image.jpg 0.25 tiled
```

Сохранит `path/to/image_pred.jpg` и напечатает статистику (кол-во по
классам, total detections, weed coverage %, время обработки).

## Веб-демо

```bash
streamlit run app.py
```

В интерфейсе: загрузка изображения → оригинал → обработанное изображение
с bbox (цвет = класс) → количество по видам сорняков, total detections,
weed coverage %, время обработки. Слайдер confidence threshold и
переключатель режима инференса:

- **Tiled UAV inference** (по умолчанию) — изображение режется на
  перекрывающиеся тайлы, детекция выполняется на каждом тайле, боксы
  пересчитываются в координаты исходного изображения и объединяются
  через NMS. Предназначен для больших снимков с дрона.
- **Standard inference** — один проход по всему изображению.

## Структура проекта

```
app.py                    # Streamlit web-демо
src/prepare_dataset.py    # генерация YOLO-разметки из classification-датасета
src/train.py               # обучение YOLOv8
src/tiled_inference.py    # тайлинг + NMS-объединение детекций
src/inference.py           # загрузка модели, единая точка входа standard/tiled
src/visualize.py           # отрисовка боксов, расчёт coverage %
data/                       # сгенерированный YOLO-датасет (data.yaml, images/, labels/)
models/best.pt              # обученные веса (появляются после train.py)
runs/                       # логи и артефакты обучения ultralytics
```

## Известные ограничения

- Bbox-разметка получена автоматически (ExG-сегментация), а не вручную —
  это приближение, а не точная разметка объектов. Для продакшна нужна
  ручная разметка хотя бы части датасета.
- Обучение и данные не различают фазу роста (розетка/стеблевание) —
  только вид сорняка, т.к. этого требует ТЗ.
- Модель обучалась на кропах отдельных растений на однородном фоне, а не
  на реальных UAV-снимках полей — точность на настоящих дрон-фото может
  быть ниже, чем на валидации. Тайлинг компенсирует масштаб, но не
  доменный сдвиг (освещение, ракурс, смешанная растительность).
- Обучение выполнялось на CPU (в окружении нет GPU) — при наличии CUDA
  используйте `--device 0` для ускорения.
